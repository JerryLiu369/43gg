## 1. 产品概览与核心理念

- **核心体验定位**：
  1. **统一工作区大厅**：作为多应用容器的门户，提供如精品出版物目录般清晰、宁静的浏览、检索与一键启动体验；子应用按需加载、运行期隔离，返回大厅时完整释放图形与音频资源。
  2. **《吉星包租公》**：一款结合「4×5 棋盘滚轮构筑 + 主动空间微操 + 房产装修经营」的单人策略肉鸽游戏。玩家扮演不同背景的房东，在每期账单到期前招募租客与奇物符号、改造公寓格子、调配相邻站位，打出爆发式连锁收益以支付节节攀升的物业账单。
- **核心价值提升**：
  - **视觉降噪与秩序感**：消除常见模板的杂乱徽章与伪技术黑话，让内容、排版层级与真实操作成为唯一主角。
  - **化纯随机为高上限博弈**：原版《幸运房东》在按下旋转后玩家完全被动且后期极易卡满废牌；本作通过**三连升星腾出空位**、**锁定与相邻调换精准触发连携**以及**格子永久装修**，让每一局都兼具构筑爽感与走位微操乐趣。

## 2. 用户体验与视觉设计规范

### A. 关键用户流

1. **应用大厅浏览与直达**：
   - 顶栏采用简洁三区结构：左侧单一品牌字标、中部单行视图导航锚点（全部应用 / 策略桌面 / 拟真竞速 / 架构说明）、右侧快速启动主入口（直达最新主打应用《吉星包租公》）。
   - 主体采用瑞士非对称网格：上方为精炼导语与实时分类筛选条，下方为结构严整的应用展陈序列。每项应用以自然序号、主标题、平实功能概述、纯文本分隔元数据（`·` 连接，零胶囊边框）及明确的「启动应用」按钮呈现。
2. **《吉星包租公》开局筹备**：
   - 选择**房东角色**（4 位机制迥异的房东，各自拥有专属初始牌组倾向、主动控盘充能特性与初始装修格）与**进阶阶梯等级**（随通关逐级解锁更高挑战），或一键读取上次未完结的自动存档继续收租。
3. **核心回合循环（旋转 → 微调控盘 → 连携结算 → 选牌/装修）**：
   - **旋转落位**：点击「开始收租」驱动 5 列账本滚轮依次停驻，落位过程伴随清脆算盘与纸牌声效（支持倍速切换与静音）。
   - **微操窗口（可选主动技）**：玩家可消耗当期持有的「调度令」执行**锁定关键格**（下轮固定原位）、**单列重摇**（重转表现不佳的一列）或**相邻调换**（将相邻两格对调以凑齐邻接加成或三连合成）。
   - **连锁结算与跳字**：棋盘按清晰顺序高亮触发相邻加成、吞噬成长、消除爆发与房型倍率，右侧账单流水实时滚动列出本轮主要收益来源，总金币以等宽字体精准跳增。
   - **三连升星提示**：当棋盘或牌库凑齐 3 个同名基础符号时，可在整备阶段一键合成为二星精装形态，浓缩体积并解锁强力新词条。
   - **选牌与房型装修**：每次旋转后从 3 张候选租客/符号卡中择一入库（或跳过领补贴、消耗移除券精简牌库）；定期开放「装修商店」与「遗物契约」，可将棋盘任意普通格永久升级为功能房型。
4. **交租大考与催租事件**：
   - 每完成指定旋转次数迎来交租结算。交租成功后进入下一阶段，不仅解锁遗物三选一，还可自主决定是否签署一份**高风险高回报契约**（例如：接下来 5 轮每轮少 1 次选牌机会，换取随机两格免费装修为黄金旺铺），并应对特色阶段事件（如黄金周消费热潮、梅雨季维修检定等）。
   - 达成全部 12 期房租目标即宣告胜利，玩家可选择结算荣誉记录，或直接转入**无尽阶梯模式**冲击极限单轮收益；同时随时可打开**全图鉴抽屉**查阅已解锁的符号、遗物、装修房型与流派搭配统计。

### B. 视觉识别与主题系统（KFL 瑞士网格纸感浅色）

- **色彩分配（严格执行 60-30-10 比例与无色盲单色依赖）**：
  - **60% 主画布（温暖典藏纸感）**：柔和米白底色 `#FAF8F4`（`--bg-canvas`），长时间凝视不刺眼。
  - **30% 结构表面与边框**：纯净卡片纸面 `#FFFFFF` 与浅亚麻次级面 `#F2EFE9`，配合温润石色 1px 细线 `#E4DFD5`（不叠加厚重阴影，杜绝左侧粗色条与多余外发光）；主墨色正文 `#1C1917`、次级说明 `#57534E`、辅助元数据 `#78716C`。
  - **10% 焦点强调色**：朱砂印章红 `#C2410C` / 琥珀金 `#B45309` 用于主行动按钮与关键倍率跳字；翡翠绿 `#15803D`、深青蓝 `#1D4ED8`、紫檀色 `#7E22CE` 仅配合明确文字标签区分罕见度与房型功能（绝不单靠颜色传递状态）。
- **字体排印层级（2+1 字体法则）**：
  - **展示与大标题**：使用兼具现代力量感与秩序感的几何标题体配中文黑体，启用紧凑字距与均衡断行，杜绝孤字尾行。
  - **正文阅读**：采用清晰易读的现代无衬线字体，控制单行阅读宽度与舒适行高。
  - **数据、金币与计时指标**：统一采用等宽数字字体并开启表格对齐数字特性（`tabular-nums`），确保房租进度、倍率跳字与历史榜单严丝合缝。
- **KFL 反套路约束（严格落地）**：
  - 零静态胶囊标签：流派类别、罕见度、应用技术栈均以清爽纯文本与中圆点分隔呈现；仅真正可点击的筛选切换器保留按钮分段态。
  - 零装饰性状态点与伪代码前缀：全面清除类似「在线绿点」「双斜杠英文编号」与底部虚假遥测状态栏。
  - 运动归源（Law 3）：弹窗、图鉴抽屉与选牌面板均仅使用 `transform` 与 `opacity` 实现 150–200ms 顺滑进出，从何处展开即向何处收拢，并完整兼容系统减弱动态效果偏好。

## 3. 关键产品与机制取舍

- **决策一：主动控盘采用「有限调度令充能」而非无限自由拖拽**
  - *选定方案*：锁定、单列重摇、相邻调换均消耗有限的「调度令」（随交租周期恢复，并可通过特定房东技能、快递柜符号或遗物额外获取）。
  - *原因*：若允许每轮无限自由摆放，游戏会退化为繁琐的固定解算术题，丧失滚轮肉鸽的惊喜感；有限次数既保留了摇奖悬念，又让关键回合的每一次交换与锁定充满「逆天改命」的策略爽感。
- **决策二：三连升星采用「玩家手动确认或开关自动合成」双模式**
  - *选定方案*：凑齐 3 个同名符号时高亮可合成提示，玩家可一键合并为高阶形态，也可暂时保留分身（例如某些流派需要多个独立个体铺满相邻格）。
  - *原因*：尊重高阶构筑玩家的流派自由度——前期合成腾格子防卡死，后期可根据房型加成灵活决定铺场还是精英化。
- **决策三：外壳浅色化与子应用画布隔离策略**
  - *选定方案*：工作区首页大厅、统一顶栏导航、异常恢复页及新作《吉星包租公》全面采用瑞士纸感浅色；既有硬核 3D 拉力赛子应用在其内部画布视口内维持原有的驾驶舱深色氛围。
  - *原因*：遵循 KFL 的作用域边界原则（GOV-1），既彻底满足你对浅色首页与护眼新游戏的偏好，又避免强行反转 3D 夜间车灯渲染导致既有赛车游戏对比度受损。
- **决策四：本地结构化持久化而非强制联网账号**
  - *选定方案*：使用带版本校验的浏览器本地存储保存当局实时状态、全图鉴解锁进度、房东最高阶梯记录与音效倍速偏好。
  - *原因*：作为随时打开消遣取乐的单人桌面小游戏，零登录门槛、秒开即玩、意外刷新不丢档是最核心的体验保障。

### B. 核心数据模型与八大流派设计

- **八大融合流派（60+ 符号 & 35+ 契约遗物）**：
  1. **茶饮夜市流**：招牌奶茶、珍珠椰果、外卖骑手、烧烤摊、夜市食客（高频吞噬配料、骑手跨格派送翻倍）。
  2. **萌宠招财流**：橘猫、三花猫、鱼罐头、猫爬架、招财金猫（吞噬罐头永久成长、相邻空位与宠物互拐）。
  3. **市井街坊流**：打工人、包租婆、麻将搭子、五金店老板、社区保安（人口聚集效应，凑齐麻将牌型或制服小偷爆发巨额赏金）。
  4. **园艺花果流**：向日葵、多肉盆栽、蜜蜂、洒水壶、摇钱树（配合阳光温室房型，按回合自然生长结出高价值果实）。
  5. **矿脉珍宝流**：矿工、镐头、原石、翡翠、钻石金库（敲碎矿石爆出稀有宝石与永久倍率加成）。
  6. **快递百货流**：快递包裹、智能快递柜、拆箱剪刀、盲盒手办（倒计时自动拆包或剪刀秒拆，产出惊喜符号与调度令）。
  7. **奇物博弈流**：骰子、幸运硬币、存钱罐、保险箱、江湖小偷（点数浮动、养肥存钱罐一锤敲碎获巨款）。
  8. **房产大亨流**：房产证、装修队、红头文件、拆迁款（与棋盘已装修格子数量深度挂钩的后期大核流派）。
- **棋盘与房型状态（Board & Tile State）**：
  - 固定 4 行 × 5 列共 20 个单元格；每格独立维护：`地形房型（普通格 / 黄金旺铺 / 阳光温室 / 街坊工坊 / 快递驿站 / 隔音公寓）`、`是否锁定`、`当前驻留符号实例（含星级、成长层数、倒计时）` 以及 `本轮结算明细`。
- **对局状态机（Run State Machine）**：
  - 清晰流转于：`开局角色与阶梯选择` → `待机微调态` → `滚轮旋转动画态` → `控盘干预窗口（重摇/调换/锁定）` → `逐格连锁结算态` → `战后选牌与三连合成态` → `交租大考与契约商店态` → `胜利/破产结算或转入无尽态`。

### C. 交互状态映射与闭环保障

- **大厅筛选与导航联动**：点击分类分段按钮即时过滤应用列表并显示准确计数；点击顶栏锚点平滑定位至对应区块；启动任一应用同步更新浏览器地址栏，支持浏览器前进/后退无缝切换且不丢失大厅筛选上下文。
- **棋盘微操防呆与即时预览**：开启「相邻调换」模式时，点击首个格子即高亮其上下左右可交换的合法邻格，再次点击目标格完成平滑换位并立即重新演算潜在连携提示，按 `Esc` 或取消按钮可无损退出该模式且不扣除调度令。
- **悬停/聚焦详情与图鉴检索**：鼠标悬停或键盘聚焦任一棋盘格子、候选卡牌或遗物印章时，侧边账本检视区稳定展示其基础产出、星级效果、关联流派与历史累计贡献（不弹出遮挡棋盘的浮层）；图鉴面板支持按流派、罕见度与已解锁状态筛选查阅。
- **单元测试与资源释放**：为《吉星包租公》的核心数值结算引擎（邻接判定、房型倍率、三连升星、吞噬消除与交租检定）编写独立确定性单元测试，并确保退出游戏返回大厅时清理全部动画帧定时器与 Web Audio 音频上下文。
